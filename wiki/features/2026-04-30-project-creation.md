# 프로젝트 생성

## 목적

사용자가 최소 입력과 브라우저 폴더 선택만으로 새 마케팅 프로젝트를 시작하게 하고, 이후 컨텍스트 초안 생성의 기준 레코드를 만든다.

## 사용자 흐름

1. 사용자가 프로젝트 생성 화면에 진입한다.
2. 사용자가 `프로젝트명`, `도메인`을 입력한다.
3. 사용자가 브라우저에서 `작업 폴더 선택`을 실행한다.
4. 클라이언트가 허용된 파일을 추출하고 요약 상태를 보여준다.
5. 시스템이 필수값과 입력 형식을 검증한다.
6. 사용자가 `프로젝트 생성`을 누른다.
7. 생성 성공 시 프로젝트 상세 흐름의 첫 단계인 `컨텍스트 초안` 화면으로 이동한다.
8. 백엔드에서 초기 `BrandProfile` 초안을 만들 준비 상태를 만든다.

## 입력

- `name`
  - 필수
  - 2자 이상 60자 이하
- `domain`
  - 선택
  - URL 전체 또는 호스트 문자열 허용
- `workingPath`
  - 선택
  - 브라우저에서 선택한 폴더 표시 문자열
- `sourceFiles`
  - 선택 직후 추출된 파일 목록
  - 파일명, 상대경로, 확장자, 크기, 추출 가능 여부 포함

## 출력

- 생성된 `Project`
  - `id`
  - `name`
  - `domain`
  - `workingPath`
  - `status`
- 컨텍스트 분석에 넘길 source payload 준비 결과
- 다음 단계 진입에 필요한 `projectId`

## 주요 상태

- `idle`
  - 최초 진입
- `invalid`
  - 로컬 유효성 실패
- `submitting`
  - 생성 요청 중
- `extracting-folder`
  - 클라이언트 파일 추출 중
- `created`
  - 생성 완료, 다음 단계 이동 가능
- `failed`
  - 서버 실패

## 예외 케이스

- 프로젝트명이 비어 있음
  - 생성 버튼 비활성화 또는 인라인 오류
- 도메인 형식이 불완전함
  - 저장은 허용하되 경고 문구 표시 가능
- 작업 폴더를 선택하지 않음
  - 생성은 허용 가능하지만 컨텍스트 품질 저하 경고 필요
- 브라우저가 폴더 선택 API를 지원하지 않음
  - 대체 안내 또는 수동 텍스트 입력 fallback 필요
- 사용자가 폴더 권한을 거부함
  - 재시도 버튼 제공
- 선택 폴더에 지원 파일이 없음
  - 생성은 허용하되 컨텍스트 초안은 약한 기본값으로 시작
- 같은 이름의 프로젝트가 이미 있음
  - 중복 허용 여부를 서버 정책으로 고정해야 한다
  - 1차는 허용하되 상세 화면에서 `id`로 구분하는 편이 단순하다
- 서버 생성 후 다음 화면 이동 실패
  - 생성 성공 메시지와 재진입 링크 필요

## 관련 화면

- `프로젝트 생성`

## 관련 API/서비스

- `POST /api/projects`
- 제안 서비스
  - `createProject(input)`
  - `normalizeDomain(input.domain)`
  - `extractSourceFilesFromDirectory(handle)`

## 관련 데이터 모델

- `Project`
- 후속 생성 예정
  - `BrandProfile`

## 구현 메모

- 프로젝트 생성 화면은 `문자열 입력`과 `브라우저 폴더 선택`을 구분해야 한다.
- 첫 진입에서는 `프로젝트명`, `도메인`, `프로젝트 저장`이 기본 경로이며, 폴더 연결은 접힌 보조 옵션이어야 한다.
- `workingPath`는 표기용이지만 source payload와 함께 실제 컨텍스트 초안 입력으로 사용된다.
- 클라이언트는 허용 확장자만 읽고, 추출 불가 파일 수를 별도로 보여줘야 한다.
- Step 1 수집 결과 보기에서는 저장 전에도 `상위 참조 파일`, `키워드 힌트`, `excerpt digest`를 먼저 확인할 수 있어야 한다.
- 생성 직후 별도 로딩 화면보다 바로 컨텍스트 초안 단계로 넘기고, 그 안에서 서버 draft 분석 상태를 보여주는 편이 UX가 낫다.

## 검증 방법

- 정상 입력으로 생성 후 `projectId`가 반환되는지 확인
- 폴더 선택 후 추출 파일 수와 실패 파일 수가 표시되는지 확인
- 프로젝트명 누락 시 요청 전 차단되는지 확인
- 도메인 공백/프로토콜 유무 조합이 저장 가능한지 확인
- API 미지원 브라우저에서 대체 안내가 보이는지 확인
- 권한 거부 시 재시도 경로가 있는지 확인
- 생성 직후 컨텍스트 초안 단계로 자연스럽게 이동하는지 확인
