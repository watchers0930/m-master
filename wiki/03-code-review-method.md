# 03 Code Review Method

## 위키 방식 코드 확인

코드는 단독으로 읽지 않는다. 아래 순서로 확인한다.

1. 이 변경의 목적이 무엇인가
2. 관련 위키 문서가 있는가
3. 구조상 어디에 있어야 하는 기능인가
4. 실제 코드가 그 위치에 있는가
5. 검증 규칙을 만족하는가

## 리뷰 질문

- 이 변경은 어느 기능 문서와 연결되는가
- 서비스, UI, DB 책임이 섞이지 않았는가
- 기존 위키 기준을 어기고 있지 않은가
- 새로 알게 된 구조 판단을 위키에 남겼는가

## 출력물

- 리뷰는 가능하면 코드 수정 제안뿐 아니라
  - 관련 위키 링크
  - 빠진 판단
  - 누락된 검증
를 함께 남긴다.
