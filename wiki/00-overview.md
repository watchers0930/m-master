# 00 Overview

## 제품 정의

`m-master`는 작업 폴더와 도메인을 분석해 브랜드 컨텍스트를 자동 구축하고, 이를 바탕으로 블로그를 원본으로 한 인스타그램·페이스북 콘텐츠를 생성하는 컨텍스트 기반 마케팅 플랫폼이다.

## 핵심 흐름

1. 프로젝트 생성
2. 작업 폴더와 도메인 분석
3. 브랜드 컨텍스트 구축
4. 사용자 승인
5. 주제 추천 또는 직접 입력
6. 블로그 생성
7. SNS 파생 생성
8. AI 검수
9. 이미지 생성 및 텍스트 합성
10. 발행 또는 내보내기

## 핵심 원칙

- 블로그는 원본 자산이다.
- 인스타그램과 페이스북은 파생 자산이다.
- AI 결과물은 검수 없이 확정하지 않는다.
- 공개 기준 도메인은 `m-master.vercel.app`으로 관리한다.
