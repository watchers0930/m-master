# 02 Workflow

## 구현 전

1. 규칙 문서 3개 확인
2. 관련 위키 문서 확인
3. 없으면 새 위키 문서 생성
4. 구현 범위와 검증 범위 기록

## 구현 중

- 구조 판단을 `analysis/` 또는 `features/`에 기록
- 새 예외 케이스가 나오면 바로 문서 갱신
- 반복 기능이 보이면 공통화 판단 기록

## 구현 후

1. 로컬 검증
2. 테스트 도메인 검증
3. 위키 문서 최종 반영
4. PR에 위키 참조 링크 남기기

## 금지

- 코드만 바꾸고 판단 근거를 남기지 않기
- 실제 구조가 바뀌었는데 위키를 방치하기
