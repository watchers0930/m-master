# 01 Architecture

## 계층 원칙

- `app/`
  - 라우트와 페이지 조합
- `components/`
  - 재사용 UI
- `features/`
  - 기능 단위 UI와 액션
- `server/`
  - 서비스, 리포지토리, 외부 API 연동
- `prisma/`
  - 스키마와 마이그레이션

## 책임 분리

- 페이지는 조합만 한다.
- 비즈니스 규칙은 서비스로 내린다.
- Prisma는 서버 계층에서만 쓴다.
- AI 생성, 검수, 발행은 각각 별도 흐름으로 다룬다.

## 주의점

- UI와 DB 직접 결합 금지
- 컴포넌트 안에서 비즈니스 로직 비대화 금지
- 반복 기능 복붙 금지
